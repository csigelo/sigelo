# sigelo-gate (prototype)

**Prototype, not released, not externally reviewed. Installed disabled.** A Claude Code hook
that denies privileged tools (shell, file writes, subagents, MCP tools that change things) unless
the prompt ends in a `sigelo-instruction:` line signed by an operator DID you pinned, by default
only until the turn reads outside text. It does not stop prompt injection in general.

Enabled without a config it **fails closed**: every privileged tool is denied. Before
`claude plugin enable sigelo-gate@csigelo`, make the operator key and `gate.json`
(`~/.config/sigelo-gate/gate.json`, or `$SIGELO_GATE_CONFIG`) as
[gate/README.md](https://github.com/csigelo/sigelo/blob/main/gate/README.md) says, and read its
Limits. This plugin is the user-level install: the agent's own user can edit its state and turn
it off. The hardened install (a root-owned hook and state writer) is not a plugin.

`gate.mjs` is generated by `plugins/build.mjs` from `gate/claude-code/gate.mjs`; offline, no
network, no dependencies. License: MIT.
