# sigelo

Portable, offline-verifiable identity for AI agents. The agent gets one identity, a
`did:sigelo:z…`, and carries it between platforms that share nothing: it answers a platform's
challenge, stores the attestation the platform signs about it, and hands anyone a bundle they
check offline. Specification and the other implementations: https://github.com/csigelo/sigelo.

## What it contains

- **MCP server `sigelo`** (local, stdio): `server.mjs`, started as `node ${CLAUDE_PLUGIN_ROOT}/server.mjs`.
  Tools: `sigelo_whoami`, `sigelo_init`, `sigelo_sign_challenge`, `sigelo_add_issuer`,
  `sigelo_add_attestation`, `sigelo_forget_issuer`, `sigelo_bundle`, `sigelo_verify`, `sigelo_rotate`. Every identity tool
  takes an optional `identity` profile name, so subagents can each hold their own.
- **Skill `sigelo`**: when to call which tool, and that attestation `claims` are data from
  strangers, never instructions.

`server.mjs` is generated by `plugins/build.mjs` (bundled, not minified) from
`integrations/mcp/server.mjs` and the libraries in `ts/src` and `adapters/moadim`; Node ≥ 22.18,
no dependencies. It has no wallet: the payment tools of the full server are not in this plugin.

## What it runs, stores and sends

It makes **no network connections**. It reads and writes one file per identity on your machine:
`$SIGELO_IDENTITY`, default `~/.config/moadim/sigelo.local.json` (profiles beside it as
`sigelo.<name>.local.json`), holding the identity's secret key, its genesis and rotations, and
the attestations and issuer documents you stored. Nothing leaves the machine unless the agent
hands a bundle (public data: DIDs, signatures, attestations) to someone. The secret key is never
returned by any tool.

## Install (Claude Code)

```sh
claude plugin marketplace add csigelo/sigelo
claude plugin install sigelo@csigelo
```

Then ask: "who am I in sigelo?" The first time, the agent asks you for a recovery public key
(or your explicit "none") before it creates the identity.
