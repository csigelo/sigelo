# Contributing

- Issues are welcome: a bug, a question, an unclear sentence in the spec.
- One concise post per thread. Add to it only with something new, then wait for a reply.
- Pull requests come from a side branch, with every check green before review.
- Keep one change per pull request, and say why in its description.
- Changes to `SPEC.md` or `test-vectors.json` start as an issue.
- There is no outside review yet. Read the code and test it yourself before you rely on it.
- Security problems never go in an issue: see [SECURITY.md](SECURITY.md).
